# Product

## Register

product

## Users

Internal TTS operators who process scripts, map speakers to MiniMax voices, run batch generation, and manage voice-library capacity.

## Product Purpose

Reduce repetitive MiniMax UI work while keeping generation, downloads, and destructive voice-library operations predictable and recoverable.

## Brand Personality

Dense, direct, utilitarian.

## Anti-references

Avoid presentation-heavy dashboards, decorative surfaces, hidden automation, and destructive actions without an explicit preview.

## Design Principles

- Optimize frequent operator workflows for speed.
- Show the exact effect before irreversible actions.
- Prefer server-confirmed state over DOM assumptions.
- Keep failures partial and recoverable instead of retrying destructive operations blindly.
- Preserve the existing compact control vocabulary.

## Accessibility & Inclusion

Follow existing project conventions. Keep labels and state messages explicit and do not rely on color alone for destructive-operation feedback.
